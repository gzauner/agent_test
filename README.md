# agent_test

## Windows desktop launcher for Miniconda `opencv` + Spyder

Use `/tmp/workspace/gzauner/agent_test/open_spyder_opencv.bat` as the desktop launcher script on Windows.

1. Copy the `.bat` file to your Windows Desktop (or create a shortcut to it).
2. Double-click it.
3. It opens a Miniconda CLI window, activates the `opencv` environment, and launches Spyder.
