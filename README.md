# agent_test

## Windows desktop launcher for Miniconda `opencv` + Spyder

Use `/tmp/workspace/gzauner/agent_test/open_spyder_opencv.bat` as the launcher script on Windows.

1. Run `/tmp/workspace/gzauner/agent_test/create_desktop_icon.bat` once.
2. This creates a desktop icon named `Spyder (opencv)`.
3. Double-click that desktop icon.
4. It opens a Miniconda CLI window, activates the `opencv` environment, and launches Spyder.
